# AMOV P450 Jetson Xavier NX Handoff

這個 repository 用於 Windows 與 Ubuntu Codex CLI 之間交接 AMOV P450 的 Jetson Xavier NX 系統重建工作。

請先閱讀：

1. `JETSON_HANDOFF_MASTER.md`
2. `JETSON_HANDOFF_COMMANDS.md`
3. `JETSON_HANDOFF_HISTORY.md`
4. `JETSON_HANDOFF_PROMPT_FOR_CODEX_CLI.md`

目前只提交交接文件，不提交 SD 映像、BSP、刷機 log、密碼或其他敏感資料。
