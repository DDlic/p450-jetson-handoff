# p450-jetson-handoff

AMOV P450 Jetson Xavier NX handoff repository for Windows and Ubuntu Codex CLI.

Read these files first:

1. `JETSON_HANDOFF_MASTER.md`
2. `JETSON_HANDOFF_COMMANDS.md`
3. `JETSON_HANDOFF_HISTORY.md`
4. `JETSON_HANDOFF_PROMPT_FOR_CODEX_CLI.md`
5. `GIT_HANDOFF_SETUP.md`
